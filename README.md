# 罗店产业招商网（静态站）

面向生物医药、医疗器械、科创研发企业、投资机构与项目方的罗店产业招商线上服务门户。纯静态网页，可部署至 **Cloudflare Pages / GitHub Pages**，数据层独立、后期可对接 **飞书多维表格** 自动更新。

## 目录结构

```
luodian-invest-site/
├── index.html          # 首页（Banner、园区概览、载体速览、政策摘要、代表企业、活动预告）
├── about.html          # 园区概况（区位交通、园区规划、产业方向、配套服务）
├── resources.html      # 载体资源（研发办公楼/标准厂房/中试车间/孵化器，可按类型筛选）
├── policies.html       # 产业政策（专项扶持/租金补贴/人才/科创奖励，PDF 下载入口）
├── companies.html      # 入驻企业名录（按赛道筛选）
├── activities.html     # 政企活动·美兰湖下午茶（预告/回顾/报名表单）
├── contact.html        # 招商对接（意向企业表单）
├── assets/
│   ├── css/style.css   # 全局样式（科技蓝+产业绿主题，响应式）
│   └── js/
│       ├── data.js     # 数据层（载体/企业/政策/活动，后期由多维表格生成）
│       └── main.js     # 交互脚本（导航、卡片渲染、筛选、表单校验）
└── README.md
```

## 本地预览

直接用浏览器打开 `index.html` 即可，无需安装依赖、无需构建。

## 部署到 Cloudflare Pages

1. 将 `luodian-invest-site` 目录推送到 Git 仓库（GitHub / Gitee 均可）。
2. 登录 Cloudflare → Workers & Pages → Create → Pages → Connect to Git。
3. 选择仓库，构建命令留空（纯静态），输出目录填 `.` 或不填，保存。
4. 部署完成后可获得 `*.pages.dev` 免费域名；在 Cloudflare 绑定自有域名并自动开启 HTTPS。

## 部署到 GitHub Pages

1. 推送仓库后，进入仓库 Settings → Pages。
2. Source 选择「Deploy from a branch」，分支选 `main`，目录选 `/ (root)`。
3. 保存后访问 `https://<用户名>.github.io/<仓库名>/`。

## 数据维护（飞书多维表格对接）

当前站点数据集中在 `assets/js/data.js`，包含 4 类数据，与方案中的多维表格一一对应：

| 页面数据 | 对应多维表格 | 关键字段 |
|---|---|---|
| 载体卡片 | 载体资源表 | 名称、类型、面积、层高、荷载、适合业态、状态 |
| 企业卡片 | 入驻企业表 | 企业名称、主营赛道、简介 |
| 政策列表 | 产业政策表 | 政策名称、分类、适用对象、摘要、PDF 链接 |
| 活动列表 | 政企活动表 | 活动名称、类型、时间、地点、状态 |

**已创建的多维表格数据源**：罗店产业招商网-数据源
- 地址：https://my.feishu.cn/base/Uh1hbU3NqaZYgtstPIrczxpGn5f
- 共 5 张表：载体资源表、入驻企业表、政企活动表、产业政策表、招商线索表（已含示例数据）
- 招商线索表用于承接网站招商表单提交的线索，按「待跟进 / 已联系 / 已转化 / 无效」跟进

**自动更新方案（推荐）**：用 GitHub Actions 定时（如每日）调用飞书开放平台 API 读取多维表格 → 生成 `data.js` → 触发站点重新构建部署。维护人员只改表格，不改代码，数据改动最多延迟一天生效。

**表单对接**：`contact.html` 提交的表单正式上线时应 POST 至 Cloudflare Worker，由 Worker 校验后写入多维表格「招商线索表」。当前为本地演示（结果输出到浏览器控制台）。
